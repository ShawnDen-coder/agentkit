## 1. adapter:langchain-native `@tool`(阶段 1)

**文件:`packages/agentkit-runtime/src/agentkit_runtime/adapter_tools.py`(新)**

adapter 厂商不写 verb schema,只实现 `ComponentAdapter`(数据契约);runtime 提供 `adapter_tools()` 把它包成 langchain `@tool`。artifact 由 profile 注入的 `to_artifact` hook 发射,runtime 不嗅探。

```python
"""adapter_tools: bind a ComponentAdapter's methods to langchain @tool objects.

The 7 backend verbs are NOT frozen in core (0.3.0) - they live here as langchain
tools, schema derived from the @tool function signature. The adapter's data
contract (ComponentAdapter Protocol) is frozen; tool exposure is langchain-native.
"""
from __future__ import annotations

import json
from typing import Any

from langchain_core.callbacks import adispatch_custom_event
from langchain_core.runnables import RunnableConfig
from langchain_core.tools import BaseTool
from langchain_core.tools import StructuredTool
from pydantic import BaseModel
from pydantic import Field

from agentkit_protocol import ComponentAdapter
from agentkit_protocol import SessionContext


# Profile-injected hook: turn a ComponentData dump into an Artifact (or None).
# agentkit_bi provides to_table_artifact; agentkit_dcc provides to_scene_artifact.
# None means "this data has no artifact form" (runtime does NOT guess).
ToArtifact = Callable[[dict[str, Any]], "Artifact | None"]


def adapter_tools(
    adapter: ComponentAdapter,
    *,
    to_artifact: ToArtifact | None = None,
) -> list[BaseTool]:
    """Build langchain tools for the 7 backend verbs (adapter data methods).

    Each tool: emit a 'status' side-channel event, call the adapter, emit an
    'artifact' event if the profile hook returns one, return JSON.
    """
    async def _get_catalog(config: RunnableConfig) -> str:
        ctx: SessionContext = config["configurable"]["ctx"]
        await adispatch_custom_event("status", {"status": "running", "label": "正在获取目录"}, config=config)
        components = await adapter.list_components(ctx)
        result = {"components": [c.model_dump(by_alias=True) for c in components]}
        await _maybe_artifact(result, to_artifact, config)
        return json.dumps(result)

    async def _get_component_data(
        config: RunnableConfig,
        component_id: str = Field(..., description="The component to fetch"),
        input_args: dict[str, Any] = Field(default_factory=dict, description="Filter/sort args"),
    ) -> str:
        ctx: SessionContext = config["configurable"]["ctx"]
        await adispatch_custom_event("status", {"status": "running", "label": "正在获取数据"}, config=config)
        component = await adapter.get_component(ctx, component_id)
        data = await adapter.get_component_data(ctx, component, input_args)
        result = data.model_dump()
        await _maybe_artifact(result, to_artifact, config)
        return json.dumps(result)

    # ... refine_component, get_selection, get_semantic_model same pattern ...

    return [
        StructuredTool.from_function(None, coroutine=_get_catalog, name="get_catalog",
            description="List available components/datasets."),
        StructuredTool.from_function(None, coroutine=_get_component_data, name="get_component_data",
            description="Fetch data for a component."),
        # ...
    ]


async def _maybe_artifact(result: dict, to_artifact: ToArtifact | None, config: RunnableConfig) -> None:
    """If the profile provides a to_artifact hook and it returns one, emit it."""
    if to_artifact is None:
        return
    artifact = to_artifact(result)
    if artifact is not None:
        await adispatch_custom_event("artifact", {"artifact": artifact}, config=config)
```

**要点:**
- 7 后端 verb **不在 core**(撤回 `verbs.py` 的 `BACKEND_VERBS` 冻结)。
- schema 从 `@tool` 函数签名推导(pydantic `Field`),不再 `create_model` 合成。
- `_maybe_artifact` 改为 profile hook,runtime 不嗅探 `columns`/`rows`。
- `VERB_STATUS_LABELS` 硬编码中文标签保留在 runtime(或下沉 profile,待决 Q3)。
- `stub verb`(`get_skill_content`/`execute_tool`)M4/M6 落地前**不进** `adapter_tools` 输出。

## 2. 前端 verb:langgraph-native `interrupt()`(阶段 2)

**文件:`packages/agentkit-runtime/src/agentkit_runtime/frontend_tools.py`(新)**

4 前端 verb 用 `interrupt(args)` 暂停图 —— 这是 langgraph HITL 的母语形态。不再用 `FrontendActionRequested` 异常。

```python
"""frontend_tools: 4 frontend verbs as langchain tools that call interrupt().

These are the ONLY verbs in core's frozen catalogue (narrow waist ②: the
FunctionCall round-trip contract). A frontend-verb tool calls langgraph
`interrupt(args)`, which pauses the graph. The orchestrator's run() catches
the resulting GraphInterrupt (surfaced as on_tool_error in astream_events v2),
yields a CopilotFunctionCall SSE, and ends the stream. The frontend executes
and re-POSTs with thread_id + Command(resume=result) to continue.
"""
from __future__ import annotations

from typing import Any

from langchain_core.runnables import RunnableConfig
from langchain_core.tools import BaseTool
from langchain_core.tools import StructuredTool
from pydantic import Field

from langgraph.types import interrupt


def frontend_tools() -> list[BaseTool]:
    """Build the 4 frontend-verb tools (UI actions that pause for human input)."""

    async def _add_component_to_dashboard(
        config: RunnableConfig,
        component_id: str = Field(..., description="The component to add"),
    ) -> dict[str, Any]:
        """Add a component to the dashboard (frontend UI action)."""
        return interrupt({"component_id": component_id})

    async def _update_component_in_dashboard(
        config: RunnableConfig,
        component_id: str = Field(..., description="The component to update"),
        changes: dict[str, Any] = Field(default_factory=dict, description="Changes to apply"),
    ) -> dict[str, Any]:
        """Update an existing dashboard component (frontend UI action)."""
        return interrupt({"component_id": component_id, "changes": changes})

    # ... manage_navigation_bar, assign_tasks_to_agents ...

    return [
        StructuredTool.from_function(None, coroutine=_add_component_to_dashboard,
            name="add_component_to_dashboard",
            description="Add a component to the dashboard (frontend UI action)."),
        # ...
    ]
```

**要点:**
- 4 前端 verb **仍在 core 冻结**(窄腰 ② 的 FunctionCall 回环契约);但它们的**实现**是 langchain `@tool` + `interrupt()`,不在 core。
- `interrupt(args)` 的 `args` 就是 `CopilotFunctionCall.arguments` 的来源。
- 不再 `raise FrontendActionRequested`。

## 3. orchestrator:有状态 + 无状态双模式(阶段 2,4)

**文件:`packages/agentkit-runtime/src/agentkit_runtime/orchestrator.py`(改写)**

```python
"""LanggraphOrchestrator: stateful (default) + stateless modes, both idiomatic.

Stateful (recommended): create_agent + checkpointer + thread_id. Frontend verbs
    call interrupt(); run() catches GraphInterrupt via on_tool_error, yields
    CopilotFunctionCall, ends stream. Frontend resumes with thread_id +
    Command(resume=result).
Stateless: no checkpointer. State lives in request.messages. Frontend verbs
    still use interrupt(), but a per-request MemorySaver is used and discarded
    (state lives only within the request). The wire contract is the same.
"""
from __future__ import annotations

from collections.abc import AsyncIterator
from typing import Any

from langchain.agents import create_agent
from langchain.agents.middleware import ToolErrorMiddleware
from langchain_core.language_models import BaseChatModel
from langchain_core.tools import BaseTool
from langgraph.checkpoint.memory import InMemorySaver
from langgraph.errors import GraphInterrupt
from langgraph.types import Command

from agentkit_protocol import BaseSSE
from agentkit_protocol import ComponentAdapter
from agentkit_protocol import CopilotFunctionCall
from agentkit_protocol import CopilotMessageArtifact
from agentkit_protocol import CopilotMessageChunk
from agentkit_protocol import CopilotPromptSuggestions
from agentkit_protocol import CopilotStatusUpdate
from agentkit_protocol import QueryRequest

from agentkit_runtime.adapter_tools import adapter_tools
from agentkit_runtime.frontend_tools import frontend_tools


class LanggraphOrchestrator:
    """LLM-backed orchestrator: langchain create_agent + langgraph checkpointer."""

    def __init__(
        self,
        llm: BaseChatModel,
        adapter: ComponentAdapter,
        *,
        checkpointer: Any = None,  # default: InMemorySaver() per-request (stateless-ish)
        extra_tools: list[BaseTool] | None = None,  # skill/MCP injection hook
        max_hops: int = 5,
        system_prompt: str | None = None,
    ) -> None:
        self._max_hops = max_hops
        tools = [*adapter_tools(adapter), *frontend_tools(), *(extra_tools or [])]
        self._agent = create_agent(
            llm,
            tools=tools,
            middleware=[ToolErrorMiddleware(aon_error=_on_tool_error)],
            checkpointer=checkpointer or InMemorySaver(),
            system_prompt=system_prompt,
        )

    async def run(self, request: QueryRequest) -> AsyncIterator[BaseSSE]:
        """Yield the SSE stream. Stateful: uses request.thread_id. Stateless: generates one."""
        yield CopilotStatusUpdate(status="thinking", label="思考中")

        thread_id = request.thread_id or f"req-{id(request)}"
        config: dict[str, Any] = {
            "configurable": {"thread_id": thread_id, "ctx": request.session_context},
            "recursion_limit": self._max_hops * 2 + 2,
        }
        # Resume from a previous interrupt if the frontend sent a result.
        input_payload: dict[str, Any]
        if request.resume is not None:
            input_payload = {"messages": [], "resume": Command(resume=request.resume)}
        else:
            from langchain_core.messages import convert_to_messages
            messages = convert_to_messages([m.model_dump() for m in request.messages])
            input_payload = {"messages": messages}

        try:
            async for ev in self._agent.astream_events(input_payload, version="v2", config=config):
                sse = _map_event(ev)
                if sse is not None:
                    yield sse
        except GraphInterrupt as gi:
            # Fallback if not caught via on_tool_error (defensive).
            interrupt_value = gi.interrupts[0].value if gi.interrupts else {}
            yield CopilotFunctionCall(name="<frontend-verb>", arguments=interrupt_value)
            return

        yield CopilotPromptSuggestions(suggestions=_CANNED_SUGGESTIONS)


def _map_event(ev: dict[str, Any]) -> BaseSSE | None:
    """Translate astream_events(v2) onto SSE events."""
    kind = ev.get("event")
    if kind == "on_chat_model_stream":
        chunk = ev.get("data", {}).get("chunk")
        text = getattr(chunk, "content", "") if chunk is not None else ""
        if isinstance(text, str) and text:
            return CopilotMessageChunk(text=text)
        return None
    if kind == "on_tool_error":
        # interrupt() surfaces here: GraphInterrupt with .interrupts tuple.
        err = ev.get("data", {}).get("error")
        if isinstance(err, GraphInterrupt) and err.interrupts:
            interrupt_obj = err.interrupts[0]
            return CopilotFunctionCall(
                name=interrupt_obj.id or "<frontend-verb>",  # verb name lookup TBD
                arguments=interrupt_obj.value if isinstance(interrupt_obj.value, dict) else {},
            )
        return None
    if kind == "on_custom_event":
        name = ev.get("name")
        data = ev.get("data", {})
        if name == "status":
            return CopilotStatusUpdate(status=data.get("status", "running"), label=data.get("label"))
        if name == "artifact":
            artifact = data.get("artifact")
            if artifact is not None:
                return CopilotMessageArtifact(artifact=artifact)
        return None
    return None


async def _on_tool_error(exc: Exception, request: Any) -> str | None:
    """ToolErrorMiddleware handler: NotImplementedError -> ToolMessage; GraphInterrupt propagates."""
    if isinstance(exc, NotImplementedError):
        return f"not implemented: {exc}"
    return None  # GraphInterrupt propagates (caught in run() or surfaces as on_tool_error)
```

**要点:**
- `extra_tools` 参数是 skill/MCP 注入 hook(阶段 1 承诺的 idiomatic 扩展点)。
- `checkpointer` 默认 `InMemorySaver()` —— 无状态模式 = 临时 checkpointer + 请求结束丢弃(本质上状态只在请求内)。
- `interrupt()` 经实测在 `astream_events(v2)` 表现为 `on_tool_error` 携带 `GraphInterrupt`;
  `_map_event` 检查 `isinstance(err, GraphInterrupt)` + `err.interrupts[0].value` 拿到 args。
- `convert_to_messages` 取代 `to_langchain_messages`(阶段 4)。
- `request.thread_id` + `request.resume` 是 0.3.0 wire 新字段(阶段 3)。

## 4. wire 协议:0.3.0 minor bump(阶段 3)

**文件:`packages/agentkit-protocol/src/agentkit_protocol/models.py`(增量改)**

```python
PROTOCOL_VERSION = "0.3.0"  # was 0.2.0


class QueryRequest(BaseModel):
    model_config = ConfigDict(extra="forbid")

    messages: list[Message]
    session_context: SessionContext
    protocol_version: str = PROTOCOL_VERSION

    # 0.3.0 additions (additive, optional - backward compatible):
    thread_id: str | None = None  # stateful mode: resume an existing thread
    resume: dict[str, Any] | None = None  # stateful mode: result from a prior CopilotFunctionCall
    tools: list[dict[str, Any]] | None = None
    features: dict[str, bool] | None = None
    workspace_options: dict[str, Any] | None = None


class Message(BaseModel):
    model_config = ConfigDict(extra="forbid")

    role: MessageRole
    content: str | None = None
    name: str | None = None
    data: dict[str, Any] | None = None
    tool_call_id: str | None = None  # 0.3.0: tighten role=tool round-trip (additive)


class CopilotFunctionCall(BaseSSE):
    event: ClassVar[str] = "copilotFunctionCall"
    name: str
    arguments: dict[str, Any] = PydanticField(default_factory=dict)
    tool_call_id: str | None = None  # 0.3.0: lets frontend correlate the round-trip (additive)
```

**要点:**
- 4 个新字段全是 `| None = None`(additive optional),不破坏 0.2.0 消费者。
- `Message.tool_call_id` 收紧 `role=tool` 回环(阶段 4 删 orphan 合成的前提)。
- `CopilotFunctionCall.tool_call_id` 让前端知道在回哪个 verb 的结果。
- minor bump 符合 `docs/contracts.md` 的 semver 政策(minor = additive field)。

## 5. authz wiring:per-verb RLS 兑现(阶段 5)

**文件:`adapter_tools.py`(补全,阶段 5)**

```python
def adapter_tools(
    adapter: ComponentAdapter,
    *,
    authorizer: Authorizer | None = None,
    to_artifact: ToArtifact | None = None,
) -> list[BaseTool]:
    """Build langchain tools with optional per-verb authorization."""

    async def _get_component_data(
        config: RunnableConfig,
        component_id: str = Field(..., description="The component to fetch"),
        input_args: dict[str, Any] = Field(default_factory=dict),
    ) -> str:
        ctx: SessionContext = config["configurable"]["ctx"]
        principal: Principal = config["configurable"]["principal"]

        # Per-verb RLS (was a no-op in M2):
        if authorizer is not None:
            await authorizer.authorize(
                principal,
                AuthzAction(verb="get_component_data", component_id=component_id, args=input_args),
            )

        await adispatch_custom_event("status", {"status": "running", "label": "正在获取数据"}, config=config)
        component = await adapter.get_component(ctx, component_id)
        data = await adapter.get_component_data(ctx, component, input_args)
        result = data.model_dump()
        await _maybe_artifact(result, to_artifact, config)
        return json.dumps(result)

    # ...
```

**要点:**
- `authorizer` + `principal` 经 `config["configurable"]` 传递(仍有点魔法,但比 M2 的 ctx-only 更明确)。
- `AuthzAction(verb=..., component_id=..., args=...)` 兑现 `auth.py` 的 per-verb RLS 承诺。
- 不再只在请求边界调 `verb="query"`(那是摆设)。

## 待你确认的直觉问题

**Q1.** `adapter_tools()` helper + `@tool` 函数签名推导 schema(替代 `create_model` 合成)—— 这符合 langchain 用户直觉吗?
